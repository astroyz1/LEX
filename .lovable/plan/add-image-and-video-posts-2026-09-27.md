# Add image and video posts

## What will change
- Add secure post-media storage for signed-in, onboarded members.
- Add media records linked to posts, with access limited to the community and file owners.
- Let members choose up to four images or one video while composing a post, preview selections, remove them, and see upload progress.
- Display post images in a responsive gallery and videos with native playback controls in the home feed.
- Clean up uploaded files if post creation fails.

## Limits
- Images: JPG, PNG, WebP, or GIF; up to 10 MB each.
- Videos: MP4, WebM, or MOV; up to 50 MB.
- A post can contain either up to four images or one video.

## Verification
- Check uploads and media rendering through the signed-in preview on desktop and mobile widths.
- Confirm access rules, application build, and relevant security checks remain healthy.
